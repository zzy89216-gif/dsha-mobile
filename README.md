# dsha-mobile

为手机重做的 DSHA 网页界面，做成 dsh 插件，不改 DSHA 本体。

当前版本 0.2.1，对应 DSHA `v26.1.0-zzy.1` 起内置。

## 有什么

- 底部标签栏：对话 / 会话 / 新建 / 设置，单手拇指就能点到。抽屉打开时底栏仍然可点。
- 侧栏改成从左边滑出的抽屉，点遮罩或选完会话自动收起；去掉电脑版左边那条窄栏，对话区占满屏宽。
- **历史对话点一下就能进**：DSHA 宿主把会话行做成「单击=选中、双击=打开」，抽屉如果在第一次点击就收起，第二次点击永远落不到那一行上。现在点会话行直接打开会话，抽屉等导航落地再收；长按、拖列表、行内 ⋯ 菜单都不算「要进去」。
- 设置面板全屏显示，分类栏改成顶部横排，关闭按钮浮在右上角，底部给手势条留白。
- 键盘弹出时底栏自动让开，对话区也不再留着底栏的空白。
- 设置 → 通用设置里新增三项，改了立刻生效：
  - 手机模式：开关整套手机布局（只在宽度小于 1024 像素时生效，平板横屏和电脑不受影响）。
  - 动态玻璃：缓慢流动的光斑背景，底栏毛玻璃。
  - 配色：默认 / 暖橙 / 青蓝 / 纯黑，深浅色都适配。

## 流畅度

- 整个插件一个 30 KB 左右的文件，不需要构建。
- 动画只用 transform 和 opacity，交给 GPU 合成，不触发重排。
- 不扫描整页，只观察侧栏开合这一个属性。
- 毛玻璃模糊只用在底栏这一小块；背景光斑用渐变，不用全屏模糊。
- 页面切到后台或系统开启「减少动画」时，玻璃背景自动静止。
- 对话列表沿用官方的虚拟列表，不重复处理。

## 安装

需要 DSHA 内置 dsh 0.2.0-rc.2 或更新版本。

在 DSHA App 的「插件」页，把下面的链接粘贴到链接输入框，按「安装插件」，确认预览：

```
https://github.com/zzy89216-gif/dsha-mobile
```

第三方插件装好后默认是停用的。在插件列表里审阅并启用 dsha-mobile，再刷新网页即可。

也可以用命令行：

```
dsh plugin --profile web add github:zzy89216-gif/dsha-mobile
```

## 和 dsh-web-mobile 一起用

两个插件同时开着不会报错，但都在改手机布局，看起来会叠在一起。建议在插件页停用 dsh-web-mobile，只留一个。同时开着时，设置里的「手机模式」下方会提示。

## 卸载

在插件页停用或删除 dsha-mobile，刷新网页，界面回到官方样式。设置保存在浏览器本地（`dsha-mobile:prefs:v1`），不会写进 dsh 配置。

## 开发与测试

纯逻辑（会话 id 解析、会话行点击该打开还是收起抽屉）有 node:test 断言，不需要浏览器：

```
node --test test/client.test.mjs
```

改 `lib/client.js` 后用 `node --check lib/client.js` 过一遍语法。
