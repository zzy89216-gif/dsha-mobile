为手机重新设计的 DSHA 网页界面，以 dsh 插件形式实现，不修改 DSHA 本体。

当前版本："0.2.1"

适用版本：DSHA "v26.1.0-zzy.1" 起内置。

有什么

- 底部标签栏： 对话 / 会话 / 新建 / 设置，方便单手操作。抽屉打开时，底栏仍然可以点击。
- 侧栏抽屉： 侧栏改为从左侧滑出的抽屉。点击遮罩或选定会话后自动收起，移除电脑版左侧窄栏，让对话区域占满屏幕宽度。
- 历史对话单击打开： DSHA 宿主原本将会话行设计为「单击 = 选中、双击 = 打开」。如果抽屉在第一次点击后就收起，第二次点击便无法落在原来的会话行上。插件调整了这一交互逻辑，点击会话行即可打开对应会话，并在导航完成后收起抽屉。长按、拖动列表及点击行内 "⋯" 菜单不会触发打开操作。
- 全屏设置面板： 设置面板改为全屏显示，分类栏调整为顶部横排，关闭按钮浮动在右上角，底部为系统手势条留出空间。
- 键盘适配： 键盘弹出时，底部标签栏自动让开，对话区不再保留多余的底栏空白。
- 三项个性化设置： 在「设置 → 通用设置」中增加以下选项，修改后立即生效：
  - 手机模式： 控制整套手机布局的启用状态。仅在视口宽度小于 1024 像素时生效，不影响平板横屏和电脑布局。
  - 动态玻璃： 提供缓慢流动的光斑背景与底栏毛玻璃效果。
  - 配色： 支持默认、暖橙、青蓝、纯黑四种配色，并适配深色与浅色模式。

流畅度

- 轻量实现： 整个插件由约 30 KB 的单个文件实现，无需构建流程。
- 动画优化： 动画主要使用 "transform" 和 "opacity"，尽量交由 GPU 合成，避免不必要的布局计算。
- 减少 DOM 观察： 不扫描整页，只观察侧栏开合相关的属性。
- 控制模糊开销： 毛玻璃模糊仅应用于底部标签栏；背景光斑使用渐变实现，不采用全屏模糊。
- 后台与减少动画适配： 页面切换到后台或系统启用「减少动画」时，动态玻璃背景自动静止。
- 复用官方虚拟列表： 对话列表沿用宿主原有的虚拟列表机制，不重复处理。

安装

需要 DSHA 内置的 dsh "0.2.0-rc.2" 或更高版本。

通过 DSHA 插件页面安装

1. 打开 DSHA App，进入「插件」页面。

2. 将以下仓库地址粘贴到链接输入框：
   
   https://github.com/zzy89216-gif/dsha-mobile

3. 点击「安装插件」，检查安装预览并确认。

4. 第三方插件安装后默认处于停用状态。在插件列表中审阅并启用 "dsha-mobile"。

5. 刷新网页，使界面变更生效。

通过命令行安装

dsh plugin --profile web add github:zzy89216-gif/dsha-mobile

注意： 本项目已停止维护。安装前请自行评估现有代码、依赖及运行环境的适用性与安全风险。

和 dsh-web-mobile 一起使用

"dsha-mobile" 和 "dsh-web-mobile" 同时启用时通常不会直接报错，但两个插件都会修改手机布局，可能产生样式或交互冲突。

建议在 DSHA 插件页面中停用 "dsh-web-mobile"，只保留其中一个插件。

如果两个插件同时启用，设置中的「手机模式」下方会显示相应提示。

卸载

在 DSHA 插件页面中停用或删除 "dsha-mobile"，然后刷新网页，界面即可恢复为官方样式。

插件设置保存在浏览器本地：

dsha-mobile:prefs:v1

这些设置不会写入 dsh 配置。

开发与测试

本项目使用 Node.js 内置的 "node:test" 进行纯逻辑测试，包括会话 ID 解析、会话行点击后应打开会话还是收起抽屉等逻辑，无需浏览器环境。

运行测试：

node --test test/client.test.mjs

修改 "lib/client.js" 后，可以使用以下命令检查语法：

node --check lib/client.js

以上命令仅供查阅现有实现及自行维护时参考。本项目已停止开发与维护，不再保证测试通过、构建环境兼容或后续问题得到修复。
